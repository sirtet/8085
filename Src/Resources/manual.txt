<PKW-3000 Simulator>

Select Hardware → PKW-3000 and load the included adapted firmware.
Use RT to run at approximately 3 MHz.

Lift the socket lever to insert, change or eject an EP-ROM file.
Supported formats: BIN and Intel HEX.

For device operation, commands and serial transfers, see the
PKW-3000 User Manual linked below.
